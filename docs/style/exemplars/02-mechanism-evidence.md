# 范文 02：把研究展开成推理

- **学习点**：研究细节的交代方式 / 指标与边界的区分 / 用对比推进论点
- **用途**：只校准机制段的展开顺序与证据密度，不提供任何可复用的观点、句子或个人经历。

## 节选

> 2010 年，Holt-Lunstad 等人在《公共科学图书馆·医学》上发过一项元分析，合并了 148 项研究、30 万多人。他们想知道：社会关系强弱，跟死亡风险到底有没有关系。
>
> 结论是有，而且效应量一点都不小。社会关系较强的人，存活概率比关系较弱的人高约 50%（OR 约 1.50）。这个效应量跟戒烟差不多，比肥胖和缺乏运动还大。
>
> 但分项结果更能说明问题。
>
> 他们拆开测了好几种指标。**"社会整合"这个复合指标 OR 是 1.91，是全部指标里最强的**：社会关系网最广、参与最多的人，优势最明显。
>
> 而单独看"独居还是一起住"这一项，**OR 是 1.19，95% 置信区间 0.99 到 1.44，跨过了 1**。这是所有指标里最弱的一个，统计上不显著。
>
> 把这两个数放在一起：**在一堆能预测"一个人过得好不好"的指标里，"他是不是一个人住"是效果最差的那个。**
>
> 1.91 和 1.19 的差距，就是这篇文章想说的全部。

## 可学的结构

1. 先交代研究的基本坐标：年份、作者、期刊、研究类型、样本规模。
2. 给出主结论和效应量，并用读者熟悉的参照物解释它的大小。
3. 主动转向"分项结果"，制造一个需要解释的差异。
4. 把关键指标写到可以被核对的程度：OR、置信区间、是否跨过 1、是否显著。
5. 最后才落到判断，而且判断只是把两个数字放在一起，不额外抒情。
6. 全程区分"这篇研究说了什么"和"我们能推出什么"。
